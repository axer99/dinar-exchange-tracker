# 💱 DinarTrack — Tunisian Dinar Exchange Tracker

Real-time exchange rate tracker across all 20 Tunisian banks with AI analysis.

## 🚀 Features
- Live scraping of 20 Tunisian banks
- AI market analysis & multilingual chatbot (AR/FR/EN)
- Rate prediction with Weighted Moving Average
- Best bank recommendation + savings calculator
- Dark mode

## 🛠️ Tech Stack
Node.js · Express.js · Axios · EJS · Cheerio · Groq AI

## ⚙️ Installation
npm i
npm run dev
